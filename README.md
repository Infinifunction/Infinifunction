# Hey, I'm Metehan 👋

### AI Developer · Software Engineer · Systems & Server Customization

I build software that goes beyond static interfaces — from **AI-powered desktop agents and intelligent web applications to network services, game server infrastructure, and deeply customized admin panels.**

I'm an independent developer interested in understanding how systems work under the hood, connecting different technologies, and turning ambitious ideas into functional software.

My work spans **Artificial Intelligence, Python development, web engineering, network services, automation, and FiveM server customization**. I enjoy working across the stack, experimenting with new architectures, and building solutions rather than relying entirely on off-the-shelf tools.

- 🤖 **AI & Agentic Systems** — Building AI assistants, multimodal agents, and tool-enabled workflows.
- 🌐 **Network & Backend Engineering** — Experimenting with networking services, APIs, monitoring, and system administration.
- 🎮 **FiveM & txAdmin Development** — Customizing server administration interfaces, localization systems, branding, and developer workflows.
- 🖥️ **Desktop Automation** — Exploring ways for AI systems to interact with applications and operating systems.
- 🎨 **Web Engineering** — Building modern interfaces, authentication experiences, and AI-oriented web applications.
- 🔬 **Systems Exploration** — Learning through hands-on development, debugging, reverse-engineering of behavior, and experimentation.

A Python-based network services project that brings several networking components together under a configurable software environment.

- WPAD-related configuration.
- SQLite-backed data management.
- Web-based administration and API functionality.

InfiniNET reflects my interest in networking beyond ordinary application development — particularly in understanding how network services interact and how they can be managed through a unified interface.
